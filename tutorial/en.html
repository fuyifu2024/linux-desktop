Getting started

Development preview: no certified system images have been released. Hardware and Windows application compatibility remain unverified.

1. Installation and backup

Back up your files and verify the image checksum. Boot PC installation media in UEFI mode. Try the desktop, then choose installation alongside Windows or erase-disk installation. Erasing deletes data on the selected disk. Stop on BitLocker or hibernated partitions and follow the installer instructions in Windows. Pi 5 requires its dedicated image; flashing overwrites the selected storage device.

2. Your desktop

Open applications from the bottom taskbar or press Super to search. Files shows your personal documents. The system menu controls network, sound and power. The layout depends on GNOME extensions; development builds may retain the upstream desktop.

3. Language and input

Choose your language in Settings → Region & Language and add input sources in Keyboard settings. Sign out and back in if requested. Switch tutorial language using the links below; all pages work offline.

4. Install Linux software

Use the graphical software manager first. The terminal example refreshes package indexes and installs VLC. APT may request your local password; typed password characters are not displayed.

sudo apt update
sudo apt install vlc

5. Windows applications

Get installers from trusted publishers. Double-click an EXE or MSI and confirm its source. Select the installed application in the manager and click Run; on first launch select its installed EXE inside that environment. Create a menu shortcut, open the uninstaller or export a log from the manager.

6. Compatibility and safety

Separate Wine environments are not security sandboxes. Windows programs may access your files. ARM64 needs an additional runtime; consult project support if it is missing. Office, Adobe applications and anti-cheat games are not guaranteed to work.

7. System updates

Use the updater or the commands below. Review proposed changes before confirming. Restart after kernel updates and back up important files before upgrading. Do not add unknown package repositories.

sudo apt update
sudo apt upgrade

8. Troubleshooting and recovery

Export failed installation logs from the manager and review personal information before sharing. Record hardware, system and application versions. If the computer cannot boot, use installation media or restore a backup rather than repeatedly formatting disks.
