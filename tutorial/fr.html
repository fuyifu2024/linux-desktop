Bien démarrer

Version de développement : aucune image système certifiée n’est disponible. La compatibilité matérielle et celle des applications Windows restent à vérifier.

1. Installation et sauvegarde

Sauvegardez vos fichiers et vérifiez la somme de contrôle de l’image. Sur PC, démarrez le support en mode UEFI. Essayez le bureau puis choisissez la coexistence avec Windows ou l’effacement du disque. L’effacement supprime les données du disque sélectionné. En présence de BitLocker ou d’hibernation, arrêtez-vous et suivez les consignes sous Windows. Le Pi 5 exige une image dédiée ; son écriture écrase le support choisi.

2. Le bureau

Ouvrez les applications depuis la barre des tâches ou recherchez avec la touche Super. Le gestionnaire de fichiers affiche vos documents. Le menu système règle le réseau, le son et l’alimentation. Les versions de développement peuvent conserver le bureau GNOME d’origine.

3. Langue et saisie

Choisissez la langue dans les paramètres de région et de langue, puis ajoutez les sources de saisie dans les paramètres du clavier. Reconnectez-vous si nécessaire. Les liens ci-dessous changent la langue du guide, disponible hors ligne.

4. Installer des logiciels Linux

Utilisez d’abord le gestionnaire graphique. Les commandes ci-dessous actualisent les index et installent VLC. APT peut demander votre mot de passe local ; les caractères saisis ne sont pas affichés.

sudo apt update
sudo apt install vlc

5. Applications Windows

Téléchargez les EXE ou MSI auprès d’éditeurs fiables. Ouvrez l’installateur et confirmez sa provenance. Dans le gestionnaire, sélectionnez l’application et cliquez sur Run ; au premier lancement, choisissez son EXE installé dans son environnement. Vous pouvez créer un raccourci, ouvrir le programme de désinstallation et exporter le journal.

6. Compatibilité et sécurité

Les environnements Wine séparés ne constituent pas un bac à sable de sécurité. Les applications peuvent accéder à vos fichiers. ARM64 nécessite un environnement d’exécution supplémentaire. Consultez la documentation s’il manque. Office, Adobe et les jeux avec anti-triche ne sont pas garantis.

7. Mises à jour

Utilisez l’outil de mise à jour ou les commandes ci-dessous. Vérifiez les changements avant confirmation. Redémarrez après une mise à jour du noyau. Sauvegardez les fichiers importants et évitez les dépôts inconnus.

sudo apt update
sudo apt upgrade

8. Dépannage et récupération

Exportez le journal depuis le gestionnaire et vérifiez les données personnelles avant partage. Notez le matériel et les versions du système et de l’application. Si le démarrage échoue, utilisez un support d’installation ou une sauvegarde plutôt que de reformater à répétition.
