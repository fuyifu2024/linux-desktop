新手教程

这是开发预览教程。正式系统镜像尚未发布；硬件和 Windows 软件兼容性仍待验证。

1. 安装与备份

先备份文件并验证镜像校验值。PC 从 UEFI 启动安装介质，先试用桌面，再选择保留 Windows 或整盘安装。整盘安装会删除目标磁盘的数据。遇到 BitLocker 或休眠分区时停止，按安装器提示在 Windows 内处理。Pi 5 使用专用镜像，烧录会覆盖所选存储设备。

2. 桌面入门

使用底部任务栏打开应用，按 Super 键搜索。文件管理器显示个人文件；右上角系统菜单可调整网络、声音和电源。布局取决于已安装的 GNOME 扩展，开发版可能仍显示上游默认桌面。

3. 语言与输入

在设置的区域与语言中选择语言，在键盘设置中添加输入源。修改后可能需要注销并重新登录。下方可切换教程语言，教程可离线阅读。

4. 安装 Linux 软件

优先使用图形化软件管理器。终端示例先更新软件索引，再安装 VLC。APT 可能要求你的本机密码；输入密码时终端不会显示字符。

sudo apt update
sudo apt install vlc

5. 运行 Windows 软件

从可信发布者获取安装包，双击 EXE 或 MSI，确认来源后安装。在管理器中选择应用并点击 Run，首次启动需选择该环境内已安装的 EXE。可以创建菜单快捷方式、打开卸载器或导出日志。

6. 兼容与安全

独立 Wine 环境不等于安全沙箱，Windows 软件仍可能访问你的文件。ARM64 需要额外运行时；提示缺失时先查看项目支持信息。Office、Adobe 和反作弊游戏不保证可用。

7. 系统更新

使用更新工具，或运行下方命令。阅读升级列表再确认。安装内核更新后重启；升级前备份重要文件。不要添加来源不明的软件源。

sudo apt update
sudo apt upgrade

8. 排错与恢复

安装失败时从管理器导出日志，分享前检查个人信息。记录硬件型号、系统版本和应用版本。电脑无法启动时使用安装介质恢复或从备份还原，不要反复格式化。
