はじめに

開発プレビューです。認証済みのシステムイメージはまだ公開されていません。ハードウェアと Windows アプリの互換性は未検証です。

1. インストールとバックアップ

ファイルをバックアップし、イメージのチェックサムを確認してください。PC は UEFI モードで起動し、デスクトップを試してから Windows と共存するかディスク全体にインストールするかを選びます。ディスク全体へのインストールはデータを削除します。BitLocker や休止状態のパーティションを検出したら中止し、Windows 側で案内に従ってください。Pi 5 には専用イメージが必要です。書き込み先のデータは上書きされます。

2. デスクトップ

下部のタスクバーからアプリを開くか、Super キーで検索します。ファイルマネージャーで個人ファイルを管理し、システムメニューでネットワーク、音量、電源を設定します。開発版では上流の GNOME レイアウトが残る場合があります。

3. 言語と入力

設定の地域と言語で言語を選び、キーボード設定で入力ソースを追加します。必要ならログインし直してください。このページのリンクで教材の言語を切り替えられます。オフラインで読めます。

4. Linux ソフトウェア

まずグラフィカルなソフトウェア管理ツールを使用してください。以下の例ではパッケージ一覧を更新して VLC をインストールします。パスワード入力中は文字が表示されません。

sudo apt update
sudo apt install vlc

5. Windows アプリ

信頼できる配布元から EXE または MSI を入手し、ダブルクリックして実行を確認します。管理画面でアプリを選び Run を押し、初回はその環境内のインストール済み EXE を選びます。メニューへの登録、アンインストール、ログの書き出しも可能です。

6. 互換性と安全性

個別の Wine 環境は安全なサンドボックスではありません。アプリは個人ファイルにアクセスできる場合があります。ARM64 には追加の実行環境が必要です。不足している場合はプロジェクトの案内を確認してください。Office、Adobe、アンチチート付きゲームの動作は保証されません。

7. システム更新

更新ツールまたは以下のコマンドを使い、変更内容を確認してください。カーネル更新後は再起動します。更新前に重要なファイルをバックアップし、不明なリポジトリを追加しないでください。

sudo apt update
sudo apt upgrade

8. 問題の解決と復旧

管理画面からログを書き出し、個人情報を確認してから共有します。ハードウェア、OS、アプリのバージョンを記録してください。起動できない場合はインストール媒体やバックアップから復旧し、むやみに初期化しないでください。
