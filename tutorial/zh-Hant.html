新手教學

這是開發預覽教學。正式系統映像尚未發布；硬體與 Windows 軟體相容性仍待驗證。

1. 安裝與備份

先備份檔案並驗證映像校驗值。PC 以 UEFI 啟動安裝媒體，先試用桌面，再選擇保留 Windows 或整碟安裝。整碟安裝會刪除目標磁碟的資料。遇到 BitLocker 或休眠分割區時停止，依安裝程式提示在 Windows 中處理。Pi 5 使用專用映像，燒錄會覆寫選取的儲存裝置。

2. 桌面入門

使用底部工作列開啟應用程式，按 Super 鍵搜尋。檔案管理員顯示個人檔案；右上角系統選單可調整網路、聲音與電源。版面取決於 GNOME 擴充套件，開發版可能仍使用上游預設桌面。

3. 語言與輸入

在設定的地區與語言中選擇語言，在鍵盤設定中新增輸入來源。修改後可能需要登出再登入。下方可切換教學語言，教學可離線閱讀。

4. 安裝 Linux 軟體

優先使用圖形化軟體管理員。終端機範例會更新套件索引並安裝 VLC。APT 可能要求本機密碼；輸入密碼時不會顯示字元。

sudo apt update
sudo apt install vlc

5. 執行 Windows 軟體

從可信任的發布者取得安裝檔，連按兩下 EXE 或 MSI，確認來源後安裝。在管理員中選擇應用程式並按 Run；首次執行需選取該環境內已安裝的 EXE。可建立選單捷徑、開啟解除安裝程式或匯出紀錄。

6. 相容性與安全

獨立 Wine 環境並非安全沙箱，Windows 軟體仍可能存取你的檔案。ARM64 需要額外執行環境；若顯示缺少元件，先查看專案支援資訊。Office、Adobe 與反作弊遊戲不保證可用。

7. 系統更新

使用更新工具，或執行下列指令。確認前請閱讀升級清單。更新核心後重新啟動；升級前備份重要檔案。不要加入來源不明的套件來源。

sudo apt update
sudo apt upgrade

8. 疑難排解與復原

安裝失敗時從管理員匯出紀錄，分享前檢查個人資訊。記錄硬體型號、系統與應用程式版本。無法開機時使用安裝媒體或備份復原，不要反覆格式化。
